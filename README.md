# concise

A [Claude Code](https://claude.com/claude-code) skill that makes Claude answer in as many sentences as the answer has core points, with no openers, closers or filler.

## Install

```bash
git clone https://github.com/fzizzle/concise ~/.claude/skills/concise
```

Then type `/concise`, or ask for concise answers. Say "stop concise" to turn it off.

## Example

> why does ice float?

Water molecules lock into an open hexagonal lattice when they freeze, which holds them farther apart than in the liquid. Ice is therefore about 9% less dense than water, so it floats.
